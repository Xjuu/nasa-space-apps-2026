# Data sources, licences and attribution

EquiFire uses only keyless, no-account data. The one optional exception is a free FIRMS `MAP_KEY` for the `/firms/*` area routes (see section 1); the demo and every other feature work without it.

Verification legend: **Verified** = the terms text was fetched and read on 2026-11-15 (or the URL was probed and answered). **Flagged** = I could not fetch the authoritative text (page empty or unreachable), or the terms are ambiguous. The wording marked "from memory" must be checked by a human before publication. This is not legal advice.
